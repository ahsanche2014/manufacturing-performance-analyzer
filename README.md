# Manufacturing Performance Analyzer

Manufacturing Performance & Loss Intelligence MVP.

## Features
- Excel/CSV upload
- Smart column mapping
- OEE, Availability, Performance and Quality
- Machine / Shift / Item filtering
- Downtime and rejection exposure
- Management diagnosis
- Excel export

Main file: `app.py`
